Como funciona

  • Alfabético: faixa de letras, ex.: A até F (aceita AA..AZ).
  • Numérico: zeros à esquerda do início são preservados (01..10 → 01, 02, … 10). Use "Dígitos" para forçar.
  • Valor fixo: um único valor para o nível.
  • Não utilizar: o endereço termina no nível anterior (ex.: só Corredor + Estante → A-01).
  • Exceções: mudam a faixa de um nível só para certos pais — ex.: a Estante 05 do Corredor B tem só 3 níveis; ou o Corredor C não tem compartimentos.
  • Use Pré-visualizar para ver conflitos antes de gravar.
